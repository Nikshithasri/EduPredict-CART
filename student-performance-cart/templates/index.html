📚 What is the CART Algorithm?

Classification and Regression Trees (CART) is a foundational supervised Machine Learning algorithm introduced by Leo Breiman. In this application, CART is used as a Classification Tree to classify students into PASS or FAIL categories.

Core Mechanics of CART:

  • Binary Splitting: Every parent node splits into exactly two child nodes (Yes / No question).
  • Gini Impurity Criterion: Measures the likelihood that a randomly chosen element would be incorrectly labeled. The split minimizing weighted Gini impurity is chosen.
  • Interpretability: The resulting decision tree generates transparent, human-readable rules that educators and students can easily inspect.

🎓 Evaluated Academic Features

The CART classifier evaluates four fundamental academic indicators to predict student semester outcomes:

1
Attendance Percentage (0–100%):

Measures classroom engagement and consistency. Strong correlation with exam readiness.

2
Daily Study Hours (0–12 hrs):

Hours devoted to self-study, problem practice, and revision outside of class lectures.

3
Internal Marks (0–100):

Midterm and sessional examinations score, reflecting core subject grasp.

4
Assignment Score (0–100):

Practical lab homework and continuous assignment submissions.
