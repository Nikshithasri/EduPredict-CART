How to Read this CART Tree:

  • Root Node: Topmost node containing all training instances. The feature with the highest information gain (greatest reduction in Gini impurity) is selected as the first split.
  • Branching: Left branch corresponds to condition evaluated as True (≤ threshold); right branch corresponds to False (> threshold).
  • Gini Value: Ranges from 0.0 (pure leaf node: 100% of samples belong to one class) to 0.5 (maximum impurity for two equally balanced classes).
  • Color Coding: Orange tint indicates probability towards Fail; Blue tint indicates probability towards Pass. Deeper color denotes higher purity.

📖 CART Algorithm Theory (Unit 5 – Combining Models)

The Classification and Regression Trees (CART) methodology builds binary trees where every internal node has exactly two outgoing branches. Unlike ID3 and C4.5 which use Information Gain / Gain Ratio (Entropy), CART standardizes on Gini Impurity.

1. Gini Impurity Mathematical Formula:

For a given node $D$ with class probabilities $p_i$ across $C$ target classes (here $C = 2$: Pass and Fail):

Gini(D) = 1 - ∑i=1C ( pi )2

Where $p_i$ is the relative frequency of class $i$ at node $D$.
• When all samples belong to a single class, $p_1 = 1.0 \implies Gini = 1 - (1)^2 = 0$ (Pure node).
• When samples are equally split between Pass and Fail, $p_1 = 0.5, p_2 = 0.5 \implies Gini = 1 - (0.25 + 0.25) = 0.5$ (Maximum impurity).

2. Finding the Best Split:

CART tests every continuous threshold for each feature and computes the weighted Gini impurity of the split:

Ginisplit(D) = (|D1| / |D|) × Gini(D1) + (|D2| / |D|) × Gini(D2)

The algorithm chooses the feature and split point that yields the greatest reduction in Gini impurity ($\Delta Gini = Gini(D) - Gini_{split}(D)$).

3. Relation to Unit 5 (Combining Models):

Single decision trees have high variance and can be sensitive to small changes in training data. In Unit 5: Combining Models, CART serves as the essential fundamental base learner for advanced ensemble methods:
• Bagging (Bootstrap Aggregating): Averages predictions of multiple unpruned CART trees.
• Random Forests: Extends bagging by randomizing feature subsets at each split.
• Boosting (AdaBoost / Gradient Boosting): Sequentially fits CART trees where each tree corrects the residuals of previous trees.
