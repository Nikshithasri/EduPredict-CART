# Student Performance Prediction Using Classification and Regression Trees (CART)

Welcome to the **Student Performance Prediction** project!

The complete application is located in the `student-performance-cart/` directory as requested in the project specifications.

### Quick Start in VS Code:

1. Open your terminal in VS Code (`Ctrl + ~`).
2. Navigate into the project folder:
   ```bash
   cd student-performance-cart
   ```
3. (Optional) Run the training script to retrain the model or regenerate plots:
   ```bash
   python train_model.py
   ```
4. Start the Flask web application:
   ```bash
   python app.py
   ```
5. Open your browser and visit:
   ```
   http://127.0.0.1:5000/
   ```

For detailed mathematical explanation of CART, Gini impurity formulas, dataset structure, screenshots, and college viva questions, see:
[`student-performance-cart/README.md`](student-performance-cart/README.md)
